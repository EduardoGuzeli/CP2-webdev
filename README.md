# README — CP2 Web Development

## 📌 Sobre o Projeto

O **CP2 WebDev** é um projeto desenvolvido para a disciplina de Desenvolvimento Web, com foco na criação de uma aplicação moderna, organizada e responsiva utilizando tecnologias front-end.

O objetivo principal do projeto é aplicar na prática conceitos fundamentais de desenvolvimento web, incluindo:

- Estruturação semântica com HTML5
- Estilização responsiva com CSS3
- Interatividade utilizando JavaScript
- Organização de arquivos e componentes
- Experiência do usuário (UX/UI)
- Versionamento com Git e GitHub

Projeto disponível em:  
https://github.com/EduardoGuzeli/CP2-webdev

# 🛠️ Como Executar o Projeto

## 1. Clone o repositório

```bash
git clone https://github.com/EduardoGuzeli/CP2-webdev.git
```

## 2. Acesse a pasta

```bash
cd CP2-webdev
```

## 3. Abra o projeto

Você pode abrir o arquivo `index.html` diretamente no navegador  
ou utilizar a extensão **Live Server** no VS Code.
